# Learn Python from Basic to Advanced

The code of every lesson of the YouTube course "Learn Python from Basic to Advanced".
Each folder holds the code of one lesson: the notebook (.ipynb) and/or the plain script (.py).

## How to run
- Notebook: open the .ipynb in VS Code (Python + Jupyter extensions) and run the cells from top to bottom.
- Script: in a terminal, in the lesson folder: `python <file>.py`
